# 🌍 Holiday-Z – Your Ultimate Travel Listing Platform ✨  

## 📖 Description  
Holiday-Z is a **travel listing platform** designed to help users discover incredible destinations, accommodations, and experiences. Built with **Node.js, Express, MongoDB Atlas, and EJS**, it provides a seamless way to explore and manage travel listings.

## 🚀 Features  
- 🌎 **Explore Listings** – Browse various travel destinations and accommodations.  
- 📝 **Reviews & Ratings** – Users can leave feedback on listings.  
- 🔐 **User Authentication** – Secure login via Passport.js for personalized interactions.  
- 💾 **MongoDB Atlas Database** – Stores listings and user data efficiently.  
- 📜 **Session Management** – Utilizes `connect-mongo` for session handling.  
- 🎨 **Dynamic UI** – Powered by EJS for interactive pages  

## 🏗 Tech Stack  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB Atlas  
- **Frontend:** EJS, Bootstrap  
- **Authentication:** Passport.js  
- **Deployment:** Render
